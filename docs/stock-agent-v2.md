# 증시 탭 개편 — 전용 에이전트 + 보유 종목 + 시간당 펄스

인터뷰(2026-07-27)로 확정한 사양. 구현 중 판단이 갈리면 이 문서가 기준이다.

## 0. 요구 요약

1. 증시를 **전용 에이전트**로 분리한다(모델 선택은 기존 공용 설정을 그대로 따른다).
2. 기존처럼 **설정한 시각에 일일 증시 리포트**를 만든다.
3. 추가로 **매시간** X·페이스북 등 시장을 움직이는 인물의 게시글 + 세계 각국 실시간 뉴스를 취합한다.
4. 보유 주식에 영향이 있으면 **문자(iMessage)** 로 알린다.
5. 보유 주식은 한국장·미국장과 **별도 탭**에서 입력한다.

## 1. 에이전트 분리

- 분리 대상은 **에이전트(프롬프트·실행 경로·도구 세트·타임아웃)** 이고, **모델은 분리하지 않는다.**
  `getAgentModel()`(대시보드에서 고른 Opus 5 / Codex)을 계속 공유한다.
- 뉴스 탭의 `국내 경제`·`미국 뉴스` 카테고리는 **건드리지 않는다.** 사용자가 "에이전트만 분리"로
  답했으므로, 뉴스 탭에서 증시 주제를 걷어내는 작업은 이번 범위 밖이다.
- 증시 에이전트는 두 개의 실행 모드를 갖는다:
  - `briefing` — 일일 리포트(기존 `curateStock` 계승)
  - `pulse` — 시간당 취합(신규)
  두 모드는 시스템 프롬프트와 출력 스키마가 다르지만 **같은 에이전트 정체성**을 공유한다.

## 2. 의견 수위 — 영향도 판정까지만

현행 프롬프트의 `⛔ 절대 규칙 1 — 투자 권유 금지`는 **유지한다.** 새로 허용하는 것은
"이 재료가 내 보유 종목에 어떤 방향으로 얼마나 세게 작용하는가"의 **영향도 판정**뿐이다.

- 허용: `방향(긍정/부정/중립)` × `강도(긴급/중요/참고)` + 판정 근거 + 리스크
- 금지: "매수", "매도", "비중확대/축소", "지금 사라/팔아라", 목표가·손절가 **제시**
  (사용자가 **입력한** 목표가·손절가를 되읽는 것은 사실 통보라 허용)
- 면책 문구(`STOCK_DISCLAIMER`)는 전 채널에서 그대로 유지한다.

## 3. 보유 종목 탭 (신규)

한국장·미국장 탭과 나란히 **별도 탭**. 입력 항목(표준):

| 항목 | 필수 | 비고 |
|---|---|---|
| 종목명 / 심볼 | ✅ | `normalizeSymbol` 로 정규화 |
| 시장 (kr/us) | ✅ | 시세 조회 경로가 갈린다 |
| 보유수량 | ✅ | 소수점 허용(해외주식 소수점 매수) |
| 평균매입단가 | ✅ | 손익률 계산의 근거 |
| 목표가 | | 없으면 null |
| 손절가 | | 없으면 null |
| **투자기간** | ✅ | `단기(수일~수주)` / `중기(수개월)` / `장기(1년+)` — 종목별로 다르다 |
| 메모 | | 자유 텍스트. 판정 프롬프트에 그대로 주입 |

- **보유 종목은 해당 시장의 등록 종목(tickers)에 자동 포함된다.** 중복 입력을 없애고,
  보유 종목이 일일 브리핑에서 빠지는 일이 구조적으로 불가능해진다.
- 현재가·손익률은 `quote.ts`(네이버) 로 서버가 계산한다. **LLM 은 손익 숫자를 만들지 않는다.**
- 투자기간은 영향도 판정의 축이다. 같은 재료도 기간에 따라 판정이 뒤집힌다
  (예: 금리 인하 기대 후퇴 → 단기 부정 / 장기 중립).

## 4. 일일 리포트 (기존 08:00 · 18:00 유지)

기존 구성(지수 · 뉴스 · 등록 종목 분석 · 관심 종목)은 **그대로 두고**, 맨 앞에
`내 포지션 점검` 섹션을 더한다:

- 보유 종목별 현재가 · 손익률 · 목표가/손절가까지의 거리
- 오늘 이 종목에 작용하는 요인(영향도 판정)
- **지난 24시간 펄스 요약** — 문자 문턱을 넘지 못한 건이 여기서 회수된다(§5 마지막 항 참고)

## 5. 시간당 펄스 (신규)

### 실행 시각
장중·장전후 집중. 한국장 `08:00~16:00` + 미국장 `22:00~06:00` 매시 정각 — 하루 약 16회.
(06~08시 · 16~22시는 건너뛴다.) 대시보드 스케줄 UI에서 조정 가능.

### 수집 소스
X 는 비로그인 접근이 대부분 막혔고 페이스북 공개 게시글 스크래이핑도 사실상 불가능하다.
따라서 **WebSearch 우회**로 간다:

- 언론이 인용한 게시글("트럼프가 X에 …라고 썼다")
- 공개 접근 가능한 미러/임베드 페이지
- 세계 각국 실시간 뉴스(로이터·블룸버그·닛케이·신화 등 + 한국 매체)

**인물 고정 명단은 두지 않는다.** 매 실행마다 에이전트가 "지금 시장을 움직인 발언"을 스스로
찾는다. 대가는 재현성 저하와 샴 인물 유입 위험 — 판정 단계에서 출처 URL 검증으로 완화한다.

### 영향도 판정
보유 종목 각각에 대해:

```
{ symbol, direction: "긍정"|"부정"|"중립", severity: "긴급"|"중요"|"참고",
  headline, rationale, risks, sources: [url] }
```

`severity` 는 투자기간을 반영해 매긴다. 근거(`rationale`)나 출처가 없으면 **항목을 폐기한다**
(기존 `normalizeAnalysisNarrative` 와 같은 정책).

## 6. 알림 정책

### 트리거 (사용자 선택)
- 인물 발언·게시글
- 보유 종목 직격 재료(실적·가이던스·공시·소송·경영진·대형 계약)
- 거시·섹터 충격(관세·규제·지정학·금리)

> 목표가·손절가 도달은 트리거로 **선택되지 않았다.** 입력은 받되 문자는 보내지 않고,
> 일일 리포트의 포지션 점검에서만 거리로 표시한다.

### 문턱과 상한
- 문턱: `중요` 이상
- 상한: **종목당 3건/일 · 전체 10건/일**, 거시·섹터 충격은 **별도 2건/일**
- 상한에 걸려 잘린 건은 로그와 원장에 남긴다(조용한 절삭 금지)

### 중복 억제
- **이슈 지문** — 제목·핵심 엔티티·종목으로 지문을 만들어 24시간 내 재발송 차단
- **강도 상승 예외** — 같은 지문이라도 `중요 → 긴급` 으로 올라가면 다시 보낸다

### 야간 처리 (23:00~07:00)
- `긴급` 만 즉시 발송
- `중요` 는 큐에 쌓아 **07:00 에 한 통으로 묶어** 발송
- 큐는 디스크에 남긴다(서버 재시작으로 소실되면 안 된다)

### 채널
- **문자만.** 시간당 펄스의 이메일은 보내지 않는다.
- 화면에도 피드를 남기지 않는다. 기존 일일 증시 브리핑 메일은 그대로 유지.
- ⚠️ 따라서 문턱 미달 건의 유일한 회수 경로는 **일일 리포트의 "지난 24시간 펄스 요약"** 이다.
  이 섹션이 빠지면 매시간 태운 토큰의 대부분이 흔적 없이 사라진다.

## 7. 비용·부하 메모

펄스 1회 = WebSearch 10~20회 + LLM 1회. 하루 16회면 일일 브리핑(2회)의 8배 규모다.
`agentQueryTimeoutMs` 를 그대로 쓰면 펄스 하나가 60분을 물고 다음 정시와 겹칠 수 있으므로
**펄스 전용 타임아웃(기본 10분)** 을 둔다. 실패는 백오프하고 그 시각은 건너뛴다
(유튜브 catch-up 백오프와 같은 패턴). 펄스는 catch-up 하지 않는다 — 지나간 시각의 실시간
취합은 보충할 가치가 없다.
